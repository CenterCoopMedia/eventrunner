Attendees#

You registered for an event and the site is not doing what you expect (sign-in code, schedule, bookmarks, materials, profile).

  1. Check the email that sent your login code, including junk and quarantine folders. University and nonprofit inboxes often hold those messages.
  2. Ask in Q&A. Say you are an attendee. Do not post your ticket number, date of birth, or full email if you can avoid it.
  3. If the event is run by the Center for Cooperative Media, you can also email info@eventrunner.org.

Event staff#

You edit the CMS, schedule, speakers, or attendees.

  • How-to and "is this supposed to work this way": Q&A
  • A product bug you can reproduce: bug form
  • A change you want on every event, not just yours: feature form
  • Your hosted site is down, a sender domain failed, or someone needs admin access: email info@eventrunner.org

Organizations that want an event site#

CCM deploys and operates one site per event. Staff run it from the admin. You do not need a developer.

Start a General thread or email info@eventrunner.org. The code is Apache-2.0. Hosting under the Event Runner name is CCM's service.
