Event Runner is the event site the Center for Cooperative Media operates for conferences and gatherings. Staff run it from an admin. Attendees sign in with Google or an emailed code. You do not need a developer to use it.

This wiki is for people using a site, not for people changing the code.

Who you are#

  • Attendee — you registered and need the schedule, sign-in, materials, or your profile
  • Event staff — you edit pages, the schedule, speakers, or attendees
  • Client — your organization wants CCM to run an event, or you are deciding whether this fits
  • Getting help — which door to knock on (Discussions, issues, email)
