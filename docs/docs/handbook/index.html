Event Runner handbook

On this page

  • Who you are

Event Runner is the event site the Center for Cooperative Media operates for conferences and gatherings. Staff run it from an admin. Attendees sign in with an emailed code, or with Google when it is enabled. You do not need a developer to use it.

Choose the guide for your role, then return here when you need help with a different task.

Who you are#

  • Attendee — you registered and need the schedule, sign-in, materials, or your profile
  • Event staff — you edit pages, the schedule, speakers, or attendees
  • Client — your organization wants CCM to run an event, or you are deciding whether this fits
  • Getting help — which door to knock on (Discussions, issues, email)
