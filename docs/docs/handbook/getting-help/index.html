Use the smallest door that fits. Public posts should not include ticket IDs, other people's emails, or anything you would not put on a flyer.

Discussions vs issues#

Discussions are for people using a site. They can be answered and closed as "answered."

Issues are the build queue. Titles stay technical so the project board and agents can sort them. The What this is column on the board is the sentence a person can read.

What not to post in public#

  • Login codes, magic-link style URLs, or session tokens
  • Spreadsheets of attendees
  • Screenshots of an admin screen that show personal data
  • Private sender-domain or billing details

Email those to info@collaborativejournalism.org if CCM is your operator.
