Glossary

Attendee — someone who registered for the event and uses the public site.

Client — the organization whose event CCM deploys. They do not touch the code.

CMS — the admin where staff edit pages, the schedule, speakers, and other content.

Embargo — a file or link that stays closed until the session ends (or staff release it).

Event staff — people with admin access who run the site day to day.

Operator — the party that deploys and hosts (CCM). Not the same as event staff.

OTP — the 6-digit emailed sign-in code.

Publish — copy a saved draft to what the public sees. Not a code deploy.

Tier A — settings fixed at deploy time (project id, providers, public URL).

Tier B — settings staff edit later (name, dates, venue, theme, badges).

White-label — the same product, with your name, colors, domain, and sender. Not a CJS-branded site with the logo swapped.
