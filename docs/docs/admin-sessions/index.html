Work with sessions in the admin

On this page

  • Create a session
  • Edit and publish
  • Change event structure

Open Sessions in the Content section of the admin docket. The register groups sessions by event day and keeps each child directly below its parent.

Create a session#

  1. Select Create a session.
  2. Enter the public title and description.
  3. Select an event day, start time, and end time.
  4. Select a track or leave it unset.
  5. Select a recorded place when the venue list includes one. The public location text remains a separate field.
  6. Select a parent only when this session belongs inside a same-day top-level session.
  7. Save the draft.

A child session can leave its track unset to inherit the parent’s track. A child cannot have another child.

Edit and publish#

The register shows whether each session is Draft, Changed, or Live. Open the session, make the change, and save the draft. A rejected save keeps the values in the form and identifies the field or relationship that needs work.

Use preview to inspect the draft in the event site. Publish only after the draft is ready. Publishing a child requires its parent to be live or included in the same publish action.

Change event structure#

Tracks, places, and movement routes live in Event settings. Add a track or place there before assigning it to a session. A place cannot be removed while a live or draft session still uses it.

The place selection is a stable internal reference. The public location field is the wording attendees read. Changing one does not rewrite the other.
