# Console forced-colour states

These previews use actual Console components with synthetic event details. The
setup view includes an unavailable step list, a completed-step tick, valid and
invalid fields, and native and ARIA-disabled actions. The Review view includes
the answer summary and its correction links. The hosting queue includes its
current status filter and a request that needs attention.

System Chromium 156 renders forced colours with both light and dark system
themes at 1280px. The field, link and button focus rings use keyboard focus.
The additional control samples show the current-stage marker and a status tag.
No live account, backend, credentials or customer data is used. These are
component previews, not production or authenticated-workflow screenshots.
