An event CMS your staff run without a developer in the room

Event Runner is a white-label event CMS. Each client event gets its own Firebase project. The Center for Cooperative Media deploys and operates it. Your staff run the site — schedule, speakers, pages, and registration — from the admin panel, without touching code.

What v1 includes

Schedule & speakers

Sessions, bookmarks, and ICS calendar links. Speaker invite, accept, profile, and approval, plus an attendee directory.

Block CMS & sign-in

A draft/publish block CMS for pages and content. Google sign-in and emailed 6-digit OTP codes for attendees.

Ticketing

Eventbrite and manual/CSV adapters on one provider-neutral registration state machine.

Full feature list, including what v1 leaves out, is in the triage record.

How it's deployed

Each client event gets its own Firebase project. The Center for Cooperative Media deploys and operates it — your data, sender domain, and ticket provider stay inside your deployment. Client staff run the site from the admin panel; they never touch a repo or a server.

The code is Apache-2.0 and free to read, fork, or self-host. "Event Runner" as a product name is reserved to CCM: that's the part that stays exclusive, not the code.

For operators

Built for nonprofits, newsrooms, universities, and event producers who want a staff-run event site — schedule, speakers, registration, and materials — without hiring developers or running infrastructure.
