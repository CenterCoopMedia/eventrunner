The show still runs when the developer is not in the room.

Run of Show is a white-label event CMS. Each client event gets its own Firebase project. The Center for Cooperative Media deploys and operates it. Your staff run the site from the admin panel.

Open the repository Read the spec

Built for people who already produce events

Staff-run CMS

Pages, schedule, speakers, materials, and branding live in the admin. Clients never touch a repo.

One project per event

Deploy-per-client. Your data, sender domain, and ticket provider stay in your deployment.

Open code, licensed name

Apache-2.0. CCM sells the operated service. The trademark is what stays exclusive.

The reference implementation is the 2026 Collaborative Journalism Summit site. That repo stays the live event. This repo is the extract.

v1 is five phases

M1

Prerequisites

Copyright, org, trademark screen, Postmark, first public commit.

M2

Core port

Config, email, OTP, CMS, schedule, profiles. A fresh project boots to a generic event site.

M3

Feature wave

Speakers, materials, media library, reactions, badges, PDF, live updates.

M4

Ticketing

Eventbrite and manual/CSV adapters on a provider-neutral registration state machine.

M5

Packaging

Runbooks, demo instance, community scaffolding, e2e in CI.
