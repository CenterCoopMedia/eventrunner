Let’s get you to the right person.

Ask us about a new event or get help with the site you run. If you are attending an event, its organizer is your first contact for tickets and registration.

I’m organizing an event.

The Event Runner team helps with setup, hosting, and the admin panel. Tell us what you are planning or what needs attention.

Email info@eventrunner.org.

I’m attending an event.

The event organizer handles tickets, registration, refunds, and event details. Look for their contact information on the event website.

If a sign-in code has not arrived, check your junk or quarantine folder before requesting another.

Read the attendee guide →

Help us understand the problem.

A few details make it easier to find the right fix. The admin panel and console also have a Report a problem action.

  • Your event name and website address
  • What you were trying to do
  • What happened, including the exact error text
  • When it started and which browser or device you used
  • A screenshot with private information removed, if it helps

If your site is down.

Email info@eventrunner.org with the site address, what you see, and when the problem started. Say that the site is down in the subject line.

Never send passwords, sign-in codes, or API keys. We will not ask you to send them by email.
