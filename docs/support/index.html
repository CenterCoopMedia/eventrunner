Support

The Event Runner team runs Event Runner and personally helps every client. Email info@eventrunner.org.

What to include

Tell us the name of your event, your site address and what you were trying to do. A screenshot helps.

Never send a password, sign-in code or API key by email. We will never ask for one.

If you are attending an event

Start with the organizer of your event. They manage registration, tickets and refunds, and their contact details are on the event site. If a sign-in code does not arrive, check your junk or quarantine folder first.

If your site is down

Email the address above with your site address and say that the site is down. Include what you see and when it started.
