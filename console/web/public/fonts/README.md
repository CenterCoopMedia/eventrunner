# Console font

Source Sans 3 uses the existing 400–700 Latin variable WOFF2 from the web
application, copied unchanged so the console serves its own assets. The
stylesheet uses `font-display: swap` and makes no font CDN request.

The font is licensed under SIL OFL 1.1. [OFL-source-sans-3.txt](OFL-source-sans-3.txt)
contains Adobe's copyright notice and the complete license, retrieved from the
[upstream Google Fonts file](https://github.com/google/fonts/blob/main/ofl/sourcesans3/OFL.txt).
