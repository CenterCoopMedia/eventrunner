# Support

## This repository

Bugs, feature requests, and questions about the code belong in [issues](https://github.com/CenterCoopMedia/run-of-show/issues) or [discussions](https://github.com/CenterCoopMedia/run-of-show/discussions).

Use the issue templates. Include the deployment version or commit, the browser, and whether you are running a fork or an operator-hosted site.

## Operator-hosted events

If the Center for Cooperative Media is operating your event site, do not file a support request in this tracker. Email info@collaborativejournalism.org. That inbox is for configuration, content, access, and anything specific to your deployment.

## Security

See [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.
