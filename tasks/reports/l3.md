# Builder l3 report

Branch `joe/wave2-l3`. Issue #476: dates and times on the event's clock, and the pitch call "saved" message.

## What changed

- `apps/web/src/lib/eventDateTime.js` converts a date and a time on the event's IANA zone to the stored UTC instant and back. It uses only Intl and UTC methods, so the browser's zone has no effect. It reports a skipped time as a gap and a repeated time as two candidates.
- `apps/web/src/admin/components/EventDateTimeField.jsx` is a fieldset with native **Date** and **Time** inputs. It names the event's zone and states the result in words, with the zone and the UTC offset for the chosen date. A skipped time is refused at once. A repeated time shows two radios. A missing part is shown after a refused save.
- **Session pitches → Manage the call for sessions**: the deadline uses the new field. The panel is no longer keyed on the saved values, so "Call settings saved." and the focus stay after the live snapshot returns. A different snapshot keeps unsaved edits and offers **Load saved settings** (`admin/pitchCallSettings.js`). The save button stays focusable while it saves. A refused save marks the deadline and the form address together. The panel description is one short sentence, and the filter and search inputs share a baseline at wide widths.
- **Ticketing → Configure ticket catalog**: the event and ticket-type sales windows use the new field, with **Clear**. A half-entered, skipped or unresolved repeated time holds the save. Times and prices are marked in one refused save. A reload mounts the date fields again, so it discards half-entered input too.
- Docs: `docs/ADMIN_GUIDE.md`, `docs/interface-guidelines.md`, `docs/operator/session-pitches.md`, `docs/operator/stripe-ticketing.md`, and two `CHANGELOG.md` entries.

## Server agreement

- `updatePitchCall` reads `closesAt` with `readClosesAt`, which stores `toISOString()`. The field sends `toISOString()`. The server still requires a deadline, and so does the field.
- `validateTicketCatalog` reads windows with `isoTime`, which stores `toISOString()` and takes blank as no restriction. The field sends `toISOString()` or null. Start and end compare as like-shaped ISO strings.
- No server or shared code changed.

## Decisions for the owner

- The pitch deadline stays required. The issue asks to "clear" a deadline and to "preserve blank semantics"; the server has always refused a blank deadline, so a cleared field refuses to save with a message.
- The conversion lives in `apps/web`, not `packages/shared`. Only the browser needs it, and a shared change forces lockfile churn.
- A time with seconds keeps its seconds. A stored 23:59:59 shows as 23:59:59.
- When the event has no valid time zone, the field uses UTC and says so.
- `docs/ROADMAP.md` has no line for #476, so nothing was ticked.
