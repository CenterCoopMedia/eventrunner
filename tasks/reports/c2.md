## Departures from the spec

1. **No `seeded`/`seededAt` sentinels in the payload.** a3's review fix makes both
   `cmsCreateContent` and `cmsUpdateContent` drop the two keys from every admin write
   (`withoutSeedFlag` in `content.cjs`), so sending `DELETE_FIELD_SENTINEL` for them would be
   dead weight. The editor sends the six fields only.
2. **`SPONSOR_PACKAGE_HINTS` lives in `admin/sponsorPackageHints.js`, not `admin/blockTypes.js`.**
   `blockTypes.js` rides the admin entry chunk (`AdminContentSection` reads its labels), and with
   the hints there the `AdminApp` chunk grew 359 gzip bytes, over the spec's 300. The hints cost
   86 of those. The only reader is the lazy block editor, so the module rides that chunk.
3. **A `url` limit of 2000 characters.** The spec's table caps every text field but the website.
   An unbounded stored string is the one field left open, so it has a cap too, mirrored in the
   editor.
4. **`shared/slug` joins `optimizeDeps.include` in `apps/web/vite.config.js`.** No web module
   imported `shared/slug` before, and the dev server (which the E2E suite runs) needs every
   linked `shared/*` entry pre-bundled for its CommonJS interop.
5. **The block editor's number fields now pass `hint`.** Without it the limit hint the spec names
   could not show. No hint on `benefits`: the richtext branch is c6's, so it is left alone.

## Decisions the owner may want to change

  session editor shows them at once). The submit stays enabled; a press with errors moves focus
  to the first invalid field.
- Order is a text field with `inputMode="decimal"`, so a non-number reaches the local check
  ("Enter a number.") instead of the browser blanking it.
- A missing tier or order reads "None" in the list.
- `sponsor_package` is appended at the end of the block palette.
- The demo prices read "Illustrative figure: 8,000" (3,000, 1,000) with no currency.
- A site whose Sponsors page was edited before this release keeps its sections (the seed does
  not refresh an edited page); the admin guide says to add the section in Pages.
- Open questions taken at their defaults: the profile fields stay out of the editor; demo ids are
  not renamed; "At the summit" in `SponsorDetail.jsx` is unchanged (it is event-specific copy the
  owner may want neutral); the wall's names are not all linked; no check at publish; the session
  editor keeps its own create path.
