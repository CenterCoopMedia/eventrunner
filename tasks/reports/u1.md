### Config and code changes

- No Vitest API change was needed. `vite.config.js` `test` block,
  `vitest.rules.config.js` (`fileParallelism`, `testTimeout`, `hookTimeout`)
  and `src/test/setup.js` work unchanged. No deprecation warnings in the run.
- `apps/web/vite.config.js`: a Rolldown `codeSplitting` group named
  `initial`. Rolldown (Vite 8) split the first-paint graph into 41 files.
  First-paint gzip grew from 280.7 kB to 289.1 kB (client) and from 282.5 kB
  to 290.8 kB (demo), against a 292 kB budget. The group puts the static
  import graph of `src/main.jsx` back into one chunk: 3 initial files
  (entry stub, Rolldown runtime, `initial`), 274.9 kB gzip client and
  277.1 kB demo. The first-paint CSS is now named `initial-*.css`; its bytes
  are unchanged.
- `apps/web/src/pages/specimen/specimenRoute.js` and `src/App.jsx`: the
  specimen page's `import()` moved beside its gate, and the gate reads
  `import.meta.env` directly instead of `IS_DEMO`. Rolldown folds a constant
  condition only in the module that holds the `import()`. With the old
  shape, a client production build wrote an unreferenced `Specimen-*.js`
  (90 kB) into `dist`. I measured each variant: literal `false` in App.jsx,
  inline env in App.jsx, and env plus import in specimenRoute.js drop the
  chunk; `IS_DEMO` from another module keeps it, also with
  `optimization.inlineConst` at `all`/2 passes. Rolldown has no option for
  it. `specimenRoute.test.js` now pins the new shape, and a test checks the
  demo comparisons match `lib/demoMode.js` (3,435 web tests, one more than
  before).
- Root `package.json`: `vite` added as a dev dependency so vitest and the
  web build resolve one vite 8; `engines.node` is now `>=22.12`, because
  Vitest 5 requires `^22.12.0 || ^24 || >=26`. CI uses `node-version: "22"`
  (latest 22.x), so CI is not affected.
- Docs: `apps/web/README.md` (toolchain versions, the `initial` chunk, the
  specimen gate), `README.md` (Node 22.12+), `CONTRIBUTING.md` (Node 22.12
  or later), `playwright.config.js` comment ("Vite 5 binds" to "Vite
  binds"), `CHANGELOG.md` entry under Unreleased > Changed.

## Decisions the owner may want to change

- The `initial` chunk group. Without it the budgets still pass, but the
  demo has 1.2 kB of gzip headroom. Dropping the group is a one-block
  revert in `vite.config.js`.
- Engines floor `>=22.12` instead of `>=22`. Vitest 5 does not run on Node
  22.0 to 22.11.
- jsdom left at 26; not required by the upgrade.
