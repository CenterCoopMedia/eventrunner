## Departures from the spec

1. **The renderer, the snapshot and the drop load on demand.** The spec put `HistorySection`, a3's
   `Timeline`, `prepareTimelineDocs` and `timelineData.js` in the eager chunk. Measured that way,
   the demo's initial chunk grew +2,423 raw / +574 gzip, leaving 190 gzip under 292,000 for c1, c6
   and c7. So `ContentContext` hands on the raw listener result as `timelineDocs` instead of a
   prepared `timeline`, and `lib/timelineEntries.js` (snapshot and drop) rides with `HistorySection`
   in its own chunk. `useHistorySection` follows the `lib/presetRemaps.js` rule: one shared load, a
   failed load forgotten so the next home page retries, and until it arrives `renderSection`
   returns `undefined`, so the page's default drawing (the section's own blocks) stands. No error
   boundary is needed. The spec's `ContentContext` cases for the prepared value moved to
   `timelineEntries.test.js`; the `ContentContext` cases cover the subscription, the pass-through,
   empty versus none, an error keeping the last set, `source`, and the draft source.
2. **No `action` prop on `HistorySection`.** `SectionHead` on this base has no action slot (c7 adds
   one), so the prop would be inert and its test could not pass. The branch that lands second adds
   the prop and passes c7's `editLink`.
3. **No `seeded`/`seededAt` sentinels in the payload** (c2's departure 1): `withoutSeedFlag` in
   `content.cjs` already drops both from every admin write. `TIMELINE_FIELDS` keeps both names so a
   caller that sends them is not refused.
4. **The admin entry chunk grew +650 raw**, over the spec's 600: three lazy routes and the chunk
   names in Vite's preload map. It is +123 gzip, at 34,985 of 50,000.
5. **Messages the spec did not word.** Server: `description: use plain text; a line break is the
   only control character allowed`. Editor: "Enter a year from 1900 to 2100." (four digits out of
   range), "Keep the title on one line, without tabs.", "Use plain text. A line break is the only
   control character allowed."
6. **An absent description is stored as `null`**, so every stored entry has the same three keys.
7. **The editor keeps the form mounted at the entry's address after a create** (c2's `createdId`
   guard), so it does not flash "No such entry" while the drafts listener catches up.
8. The `global-setup.mjs` comment also names `cmsUpdates`, which the seed already wrote.
