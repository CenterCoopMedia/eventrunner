## Departures from the spec

1. **No `action` prop on `HistorySection`.** `SectionHead` on this base has no action slot (c7 adds
   one), so the prop would be inert and its test could not pass. The spec does not need it before
   c7's slot exists; the stack adds it with that slot.
2. **No `seeded`/`seededAt` sentinels in the payload** (c2's departure 1): `withoutSeedFlag` in
   `content.cjs` already drops both from every admin write. `TIMELINE_FIELDS` keeps both names so a
   caller that sends them is not refused.
3. **The admin entry chunk grew +650 raw**, over the spec's 600: three lazy routes and the chunk
   names in Vite's preload map. It is +126 gzip, at 34,988 of 50,000.
4. **Messages the spec did not word.** Server: `description: use plain text; a line break is the
   only control character allowed`. Editor: "Enter a year from 1900 to 2100." (four digits out of
   range), "Keep the title on one line, without tabs.", "Use plain text. A line break is the only
   control character allowed."
5. **An absent description is stored as `null`**, so every stored entry has the same three keys.
6. **The editor keeps the form mounted at the entry's address after a create** (c2's `createdId`
   guard), so it does not flash "No such entry" while the drafts listener catches up.
7. The `global-setup.mjs` comment also names `cmsUpdates`, which the seed already wrote.
