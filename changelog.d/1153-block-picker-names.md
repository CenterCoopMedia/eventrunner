### Changed

- Adding a content block now shows a small example of each block type, drawn
  with the site's own theme, with a plain name and one line about it. Types a
  section does not take stay in the list, disabled, with the reason.
- Block types have plainer names: Short text, Paragraphs, Button, Number,
  Question and answer and Link (were Text, Rich text, Call to action,
  Statistic, FAQ item and Link group).
- The block editor's buttons read Save draft and Save and publish, the same
  words as the page and update editors.
- The page structure editor no longer offers "Add block". That list only set
  placeholder content for a brand-new site, so adding to it changed nothing on
  a running site. Each section now links to the screen where its content is
  written, and shows how many content blocks it holds. Stored placeholder
  lists are kept unchanged.
